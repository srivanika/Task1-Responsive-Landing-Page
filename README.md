# Task 1 – Responsive Landing Page

## Project Description
This project is a responsive landing page developed as part of my internship Task 1.

The website is designed using HTML and CSS. It provides a simple and user-friendly interface that works on desktop, tablet, and mobile devices.

## Technologies Used
- HTML5
- CSS3

## Features
- Responsive navigation bar
- Home section
- About section
- Services section
- Contact section
- Get Started button
- Responsive design for mobile devices
- Footer with social media links
